## How I Think

- Model the domain clearly. Good names and boundaries make every future change cheaper.
- Optimize for maintainers. The person debugging production later deserves empathy today.
- Ship in small, reversible steps. Big migrations are safer when the system can run old and new paths together.
- Use AI as leverage, not autopilot. The best workflows keep humans in charge of design, review, and judgment.
- Leave useful trails. Tests, docs, and pull request context are part of the product.
